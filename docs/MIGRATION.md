# 从早期 SXS 本地版迁移

1. 在独立目录和虚拟环境安装本开源版。不要直接覆盖正在运行的旧安装。
2. 运行 `sxs-control init`。只迁移需要的 `allowed_roots`，不要复制旧设备配置、令牌、日志或备份。
3. 将客户端命令改为新环境的 Python：`-X utf8 -m sxs_control --stdio`。
4. 确认 `doctor`、工具清单和实际工作流后，再自行切换旧启动项。安装器不会创建计划任务或重启服务。

工具名称兼容；`device_id` 为兼容旧调用可以传入但会被忽略。额外未定义参数、字符串代替布尔值、越界参数会被拒绝。文件信息、复制、移动、搜索和删除也统一应用 `allowed_roots`。

`clicks: 0` 与 `seconds: 0` 保持零的含义。窗口选择没有匹配结果时会报错，避免静默选到别的窗口。进程按名称终止使用完整名称（例如 `example.exe`），不会按子串批量匹配。

新 HTTP 默认端口为 18790，必须带 `X-SXS-Local: 1`。旧版没有此检查的 HTTP 客户端需要更新；PowerShell 脚本可以直接调用 CLI，无需常驻 HTTP 服务。

浏览器工具读取的是 Windows 辅助功能树，不是 DOM/CDP。标签是临时遍历编号，界面变化后需要重新截图/快照；它不是稳定的元素标识。显示器工具返回边界和数量，不承诺完整的 DPI 元数据。没有后台服务、远程管理或云端回退。
