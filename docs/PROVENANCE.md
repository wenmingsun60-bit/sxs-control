## 早期版本与这次开源版本

早期 SXS Control 把多种 Windows 控制能力接入自有服务，之后发展为 39 个工具的本地版。该工作目录没有完整记录每段代码的原始来源，因此不能据此宣称整个早期版本完全原创，也不能用一份新 LICENSE 替代所有上游义务。

本次 v0.1.0 以早期本地版的工具名称和行为作为接口参考，重新编写 `src/sxs_control/` 的配置、工具定义、协议适配、文件操作及 Windows 适配模块。开源源码不导入或执行早期私有 Agent、云端 schema 源文件、设备配置、日志、备份、部署包或历史 Git 数据。该决定使公开代码的范围可以直接审查；这不是对早期私有部署作出的来源合规认证。

Windows-MCP 和 Desktop Commander 的已知贡献单独致谢并保留 MIT 版权声明；实际运行依赖及声明见根目录 `THIRD_PARTY_NOTICES.md`。没有把上游作者的署名换成 SXS 署名，也不把工具整合描述成底层功能的独家发明。

## SXS 在本仓库维护的内容

- 保持 39 个兼容工具入口，组织统一的本地调用方式。
- MCP stdio、命令行和可选的本机 JSON HTTP 适配。
- 去除账号和云端依赖，整理安装、配置和迁移流程。
- 配置校验、统一的文件根目录检查、HTTP 本地访问检查。
- 文档、测试、缺陷处理与后续版本维护。

MIT 许可适用于本仓库新增的 SXS 代码；外部依赖及保留的上游材料继续适用各自许可。新增第三方源代码时，贡献者必须提供源项目、文件、版本/提交和许可证，保留版权/NOTICE，并先检查兼容性。
