## 覆盖的具体问题

- JSON 解析错误后仍可处理下一条请求，通知不产生回复。
- 拒绝把字符串当布尔值、把布尔值当整数，以及未知或越界参数。
- 复制的源和目标都检查路径；文件信息、搜索、移动和删除也检查路径。
- `clicks=0` 不发送鼠标按键事件；`seconds=0` 不被默认值覆盖。
- HTTP 拒绝异常 Host、带 Origin 或浏览器取回标记的请求、缺少固定本机请求头的请求，以及非 JSON 的 POST。
